# Flutter Hello World

Ứng dụng Flutter hiển thị **Hello World!** ở giữa màn hình.

Yêu cầu: Flutter 3.41.7 / Dart 3.11.5 trở lên tương thích với project.

Từ thư mục này, chạy:

```powershell
flutter pub get
flutter run -d chrome
```

Kiểm tra và build bản web:

```powershell
flutter analyze
flutter build web
```

Mã nguồn chính: `lib/main.dart`. Có cấu hình chạy Android, web và Windows. Bản build, cache và cấu hình máy cá nhân được loại khỏi Git.
