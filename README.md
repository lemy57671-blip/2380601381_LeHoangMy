## Chạy ứng dụng

```powershell
git clone https://github.com/lemy57671-blip/2380601381_LeHoangMy.git
cd 2380601381_LeHoangMy/hello_world
flutter pub get
flutter run -d chrome
```

Ứng dụng hiển thị dòng **Hello World!** ở giữa màn hình. Xem thêm [hướng dẫn của project](hello_world/README.md).
